## App Review Information Notes (yalniz EN, tek alan)

zerospike is a personal diabetes logbook (wellness/tracking). It does not diagnose, treat
or provide medical advice; any insulin figure shown is plain arithmetic from the user's own
saved ratios, and every such screen carries a "not medical advice" disclaimer. All health
data stays on the device: there is no account, no server and no upload. HealthKit is used
read-only (blood glucose, insulin delivery, workouts) to display the user's own data in the
journal; nothing is written back or shared. The SOS screen only opens the system dialer or
a prefilled message composer containing the user's location; it never places calls or sends
messages automatically. To review quickly: on a fresh install, complete the step-by-step
setup (defaults are fine), then use the sample data offer on the empty dashboard to populate
the journal, Insights and the PDF report. Subscriptions (monthly; yearly with a 7-day free
trial; one-time lifetime) run through StoreKit via RevenueCat and can be tested with a
sandbox account.
